# LLM-powered-ChatAssistance
Project on using Langchain and OpenAI API for creating a Chat Assistance

## Steps to run the code:
- Create a .env file to load the necessary keys:
  * OPENAI_API_KEY="_paste_your_openai_api_key_"
  * LANGCHAIN_API_KEY="_paste_your_langchain_api_key_"
  * LANGCHAIN_PROJECT="_paste_your_langchain_project_"
   Note: please visit langchain api and openai api website to first create an account and then API keys respectively (https://docs.smith.langchain.com/administration/how_to_guides/organization_management/create_account_api_key) and (https://openai.com/api/)
- Create a requirement.txt file to include all the relevant packages.
- Run the requirement file using "pip install -r requirements.txt"
- Run the code file using "streamlit run app.py"
